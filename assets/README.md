# Demo & Visual Assets

This directory is reserved for public-facing product visuals for Your Next Skill.

Planned assets include:

- Product demo video or demo-video link
- Landing page screenshot
- Skill assessment / level-selection screenshot
- Learning-path screenshots
- Lesson experience screenshots
- Progress or dashboard views

## Asset Guidelines

Only public-safe product visuals should be added here. Screenshots should not contain user information, private beta participant data, credentials, API keys, analytics identifiers, or protected administrative information.

The goal of this folder is to let someone reviewing the GitHub project quickly understand what the product looks like and how it works without exposing the production application.

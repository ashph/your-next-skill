# Public Roadmap

Your Next Skill is in active beta development. This roadmap describes product direction rather than fixed release commitments.

## Current: Beta Validation

- Validate the core learning experience
- Gather feedback from professionals and HR/business leaders
- Improve navigation and lesson discovery
- Improve interactivity
- Refine skill-level progression
- Evaluate engagement and lesson-start behavior

## Next

- Expand interactive learning experiences
- Strengthen capstone and applied exercises
- Improve progress visibility
- Add richer product demos and examples
- Refine recommendations for what users should learn next
- Continue testing the credit/access model

## Longer-Term Direction

- More role-specific learning journeys
- Team and organizational learning experiences
- AI enablement resources for managers and leaders
- Expanded applied AI and workflow content
- Better measurement of skill progression and practical application

## Guiding Principle

The roadmap is driven by usefulness, not feature count. New functionality should help users understand, practice, or apply an AI capability more effectively.
